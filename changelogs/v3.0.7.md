# v3.0.7

## Fixed

- **Fonts and Python packages still not splitting**: `read -ra` also uses IFS for splitting. Since `IFS=$'\n\t'` has no space, the arrays were still single-element. Fixed by using `IFS=' ' read -ra` to explicitly split on spaces.

## Added

- **Auto-source bashrc after install**: The installer now sources `~/.bashrc` at the end instead of just telling the user to do it manually.
