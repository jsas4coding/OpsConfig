# v3.0.6

## Fixed

- **Python packages and fonts treated as single string**: `IFS=$'\n\t'` at the top of the script removes space from word splitting. This caused `for pkg in ${PYTHON_PACKAGES}` and `for font_name in ${FONTS}` to treat the entire space-separated string as one token, failing validation. Fixed by using `read -ra` to split into arrays before iterating.
