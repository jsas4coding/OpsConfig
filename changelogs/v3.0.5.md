# v3.0.5

## Fixed

- **Script exits silently during cleanup_legacy**: The `[[ -L ${file} || -e ${file} ]] && rm -rf` pattern inside the for loop caused the script to exit with `set -e` when the last file in the list didn't exist — the `[[ ]]` test returned 1, making the entire line return 1, which `set -e` treated as a fatal error. Replaced with `if/fi` blocks throughout.
- **ERR trap not inherited by functions**: The script used `set -euo pipefail` but lacked `set -E` (errtrace). Without it, the ERR trap is not inherited by shell functions, so `on_error()` never fired inside `main()`. Changed to `set -Eeuo pipefail`.
- **Same pattern in setup_repository**: `[[ -d ${OPSCONFIG_REPO} ]] && rm -rf` had the same issue — if the directory didn't exist on first install, it would exit silently.
