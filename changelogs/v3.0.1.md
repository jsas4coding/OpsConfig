# v3.0.1

## Fixed

- **Install script fails when run via `curl | bash`**: The install script sourced `lib/common.sh` using a relative path based on `$0`, which resolves incorrectly when piped from curl (where `$0` is `bash`) or executed from a temporary file (during updates). The install script is now fully standalone with the common library embedded directly.
- **Color reset not working in interactive prompts**: Scripts used `${RESET}` variable for color reset, but `common.sh` only defined `${NC}`. Added `RESET` alias to `common.sh` for scripts that still source it.

## Changed

- Install script no longer depends on `lib/common.sh` — it is fully self-contained
- Bumped version to 3.0.1
