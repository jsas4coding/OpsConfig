# v3.0.2

## Fixed

- **Silent crash when required commands are missing**: When running as non-root, `install_system_packages` was skipped but `cleanup_legacy` still deleted all dotfiles. If `git` or `stow` were missing, `setup_repository` would fail silently (due to `set -e`) leaving the system without any configuration. Added `check_required_commands()` that verifies `git`, `stow`, and `curl` are available before any destructive action.
- **Wizard freezes when no TTY is available**: When running via `curl | bash` in environments without a TTY (containers, CI), `whiptail` and `read` could hang indefinitely. Added TTY detection (`_has_tty()`) — when no TTY is available, the wizard silently uses defaults instead of blocking.
- **Wizard asks root-only questions as non-root**: The PHP version question is only relevant when running as root (PHP is installed via apt). Skipped for non-root users.
- **`read` fallback reads from pipe instead of terminal**: The `read` fallback in `ask_config` and `ask_yes_no` read from stdin which is the pipe when using `curl | bash`. Changed to read from `/dev/tty` explicitly.

## Changed

- Reordered install flow: dependency check now runs before cleanup to prevent data loss
